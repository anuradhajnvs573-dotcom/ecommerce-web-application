# ecommerce-web-application
Full-stack E-Commerce Web Application built with JavaScript, Node.js, Express.js, and MongoDB.
E-Commerce Web Application

About the Project

The E-Commerce Web Application is a web-based shopping platform designed to provide users with a convenient online shopping experience. It aims to support product browsing, user authentication, shopping cart management, and order placement.

Features

- User registration and login
- Product listing and browsing
- Shopping cart management
- Order placement and checkout
- Backend API integration
- Database connectivity using MongoDB

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JSON Web Tokens (JWT)
- Development Tools: Visual Studio Code, npm, Git, GitHub

Installation and Setup

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:
   
   cd ecommerce_web_application

3. Install dependencies:
   
   npm install

4. Create a ".env" file and configure your environment variables:
   
   PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

5. Start the application:
   
   npm start

6. Open the local URL shown by the application in your browser.
